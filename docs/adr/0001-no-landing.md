# 棋子不可落在对方所在点（无吃子）

在 9 点图上双方各一枚棋子移动、靠封锁取胜的设计中，是否允许走到对方棋子所在的点是核心规则分叉。我们选择**不允许**：走到对方所在点为非法走法，胜负只通过封锁（使对方无路可走）判定。

理由：保持胜负的纯粹封锁型，规则最少、策略最干净；吃子会让游戏退化为追杀，弱化占路封锁的趣味。

## 考虑过的方案

- **A. 不可落在对方点（采用）**：对方所在点不能作为目标点；若某方唯一能走的一步恰指向对方点，视为无路可走、该方负。
- **B. 可落在对方点 = 吃子即胜**：作为**未来新模式**保留，稍后单独评估其节奏与平衡。不在 v1 实装。
- **C. 同点共存**：双方可同点，仅路径归属互斥。否决，因会削弱「逼死」的可达成性。

## 影响

因不能落在对方点，任何一方都**无法占领当前连到对方棋子的那条路径**（走过即落地于对方点，属非法）。因此封锁对方需「提前在对方周围占领路径、再将其逼入」——这是本棋的核心战术形态，也使中心点成为高价值争夺点。
