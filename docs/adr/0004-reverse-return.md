# 占领路径的二次走法：反向返回（v1），容量型为后续变体

一条被首次走过而占领的路径有 2 点容量。第 2 点容量（即添第 2 箭、关闭路径）的用法，v1 采用**限制型反向返回**：

- 占领者可再走一次该路径以添第 2 箭，但**必须是反向**（与首次走向相反），且**时机不限**--任意后续回合，只要回到首次抵达的那个端点即可补上。
- 若一直未反向走它，路径停在 1 箭：仍归此方、对方不可走，己方保留日后反向返回的选项。
- 同向复用、对方走该路径，均不允许。

理由：保留「返回一次」的字面与本意（反向＝返回），同时不引入「没立刻返回就永久作废」的苛刻边界；占领区成为一组可择机撤退的「单向返回阀」，策略上有深度且规则边界少。

## 考虑过的方案

- **A. 容量型（后续变体）**：占领过的 1 箭路径，后续任意回合、任一方向可再走一次添满。定义最简洁、占领区＝可各走一次的主场。作为**后续变体**保留，v1 不实装；待 v1 玩法验证后评估是否切换或作为可选模式。
- **B1. 即时反向返回**：第 2 箭只能紧接下一步打出，否则该线永久停 1 箭。否决，因「永久作废」边界苛刻、易堆死线、争议多。
- **B2. 任意时机反向返回（采用）**。

## 影响

- 路径状态须记 `{归属, 箭头数, 返回起点}`：返回起点＝首次走过时抵达的端点；第 2 箭仅允许从该起点反向走出。
- 合法走法判定：己方 1 箭路径仅当「当前位于其返回起点、走向对端」时可作为第 2 箭；其余情况不可走。
