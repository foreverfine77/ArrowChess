# 打开箭棋

直接双击 `web/index.html`，或项目根目录中的 `启动箭棋.cmd`，即可离线玩本地双人和人机模式。无需安装服务器，也无需先启动 Node.js。

`web/game.js` 是从当前 TypeScript 源码生成的离线脚本。修改游戏源码后，在项目根目录运行 `npm run build:web` 更新它。

开发时运行 `npm run dev`，浏览器访问 http://localhost:5174。网页会加载最新源码并支持热更新。

从 GitHub 克隆后，先运行 `npm ci`。随后可以运行 `npm test` 和 `npm run typecheck` 验证共享内核和网页版。

微信开发者工具使用单独的本地 `miniprogram/` 工程。有该工程时，上述检查也会覆盖微信小游戏。单独构建小游戏可运行 `npm run build:minigame`。

发布到静态托管时，上传 `npm run build:web` 生成的 `dist/web` 目录，不能直接上传开发入口 `web`。详见 `docs/发布检查.md`。
