# 公平性分析 (Fairness Analysis)

> 状态：初步手推结论，待穷举求解器验证。本文件记录当前推理、求解器计划与平衡方案，供后续讨论与迭代。
> 该话题当前暂搁（见文末变更记录），起始位置等依赖项确定后再继续。

## 核心问题

给定起始位置，先手是否必有必胜策略？（即「先下必赢」是否成立。）

## 前提：这是一局必分胜负的确定游戏

- 完全信息、无随机、有限步（每步消耗 1 点全局容量，最多 40 步必终局）、无路可走者负。
- 由 Zermelo 定理：给定起始位置，先手或后手**必有一方有必胜策略**；不另加和棋规则则无平局。
- 故问题实为：**先手还是后手有必胜策略**，且结论依赖起始位置。

## 论据一：偏先手 -- 中心抢占打破镜像防御

以对角 **1 与 9** 开局（180° 旋转对称）为例：

- 后手标准防御 = 镜像：P1 走哪步，P2 走旋转对称的那步，维持对称；对称下先无路者为先动的 P1 -> P2 胜。
- 但中心 **5 是 180° 旋转的不动点**：P1 第 1 步即可 `1 -> 5` 占中心（对角相邻，合法）；P2 若镜像需 `9 -> 5`，落点已被 P1 占据，按 [ADR-0001](./adr/0001-no-landing.md) 的 A 规则非法 -> **镜像破裂**。
- 中心度数最高（8 条路径），先占者机动优势最大。
- 倾向：**先手有利**。

## 论据二：偏后手 -- 容量奇偶性

- 全局容量 = 20 路径 × 2 = **40 步**，每步消耗 1。
- 若一路耗到满（40 步全用完）：P1 走奇数步（1, 3, …, 39），P2 走偶数步（2, …, 40）。
- 第 **41** 步轮到 P1，此时全图路径皆满，P1 无路可走 -> **P1 负，P2 胜**。
- 即「拖到耗尽」的长局偏后手。与论据一相反。

## 当前结论

两条论据方向相反，纯手算无法定论。**是否先手必胜，须由穷举求解器给出确切答案。**

## 求解器计划

- **状态**：双方棋子位置（9×9，去同点）+ 每条路径的归属与箭头数（20 条，每条 ∈ {未占, 红1, 红2, 黑1, 黑2}）+ 轮次。
- **方法**：带置换表（memoization）的极小极大 + alpha-beta 剪枝 + 棋盘对称归约（8 对称）。终局判定「轮到者无合法走法则负」。
- **规模**：每步分支 ≤ 8，深度 ≤ 40 ply。理论状态空间上界大（5²⁰ 量级），但可达状态远少、且对局多在远小于 40 步时因封锁提前终止；预计秒级至分钟级可解，实装后实测。
- **输出**：每种起始配置下「先手胜 / 后手胜」；可扩展为策略库与开局平衡建议。
- **触发条件**：起始位置确定后即可实装。

## 平衡方案：饼规则 (Pie Rule / Swap Rule)

- **规则**：P1 第 1 步后，P2 可选择**交换阵营**（接手 P1 的位置与已占路径，P1 变后手）。
- **效果**：P1 不敢走太强（会被换走）、不敢走太弱（P2 不换则 P1 亏），开局自动趋向平衡。
- **出处**：连接类棋（Hex 等）的标准做法；是「先手必胜」问题的稳健兜底，**无论求解器结论如何都可采用**。
- **待定**：是否采用，等求解器结果与产品定位（休闲 vs 竞技）再定。若采用，需设计交换的 UI 提示与规则说明。
